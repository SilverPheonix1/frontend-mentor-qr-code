# QR Code Component

A responsive QR code component built as part of a Frontend Mentor challenge.

## Overview

This project is a simple QR code component from Frontend Mentor meant to hep you practice your HTML and CSS skills..

I built the project from the provided desktop and mobile designs, and the tools provided from Frontend Mentor using HTML and CSS.

## My Process

### Built With

- HTML5
- CSS3
- CSS Grid
- Responsive design

### What I Did

I first created the structure of the component using semantic HTML. I then used CSS to recreate the design, including the card, QR code, typography, colours, spacing and rounded corners.

I used CSS Grid to position the component and added responsive styling so that the design works across different screen sizes.

### What I Learned

This was one of my first independent HTML and CSS projects. I practised turning a visual design into a webpage without following a step-by-step tutorial. I encountered a lot of errors on the way but I was able to learn from them using copilot in vscode and chatgpt for learning the basics of git I needed. However, I made sure they weren't writing the code for me and I understood whatever code they did give me.

I also learned how to use Git and GitHub to track my code and publish my project. During the project I had to revert a commit after making a mistake, which helped me understand how Git can be used to safely manage changes to a project. It was in using Git that I encountered most of my errors but I was able to learn and overcome my challenges.
